## Repository map

This repository uses `repoty` to maintain an AI-friendly map in `.repoty/`.

Before exploring source files, check the repoty map first:

- `.repoty/agent/SITEMAP.md` for the high-level repository map
- `.repoty/agent/ROUTES.md` for route/domain summaries
- `.repoty/agent/FILES.md` for file-level summaries
- `.repoty/agent/routes/` for per-route reading guides

Useful commands:

- `repoty status` to check whether the map is fresh
- `repoty map` to list routes/domains
- `repoty find <query>` to search the map
- `repoty explain <target>` to get a recommended reading path

If the map is stale after source changes, run `repoty update`.
